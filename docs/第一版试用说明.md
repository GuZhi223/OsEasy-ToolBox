# 第一版试用说明

> 历史原型说明。当前默认使用原工具箱界面，请参考 [原项目增强版试用说明](原项目增强版试用说明.md)。

入口：`dist/OsEasyAuto.exe`。这份单文件程序包含运行环境，可以复制到教室电脑直接运行。

## 建议的第一轮试用

1. 在原厂学生端正常运行、尚未开始广播时，打开程序并点击“开启自动模式”。
2. 查看是否记录“已连接学生端组件”。如果看到样本校验失败、权限错误或监听未连接，保留具体事件记录。
3. 让正常课堂广播开始，观察是否自动变成窗口，并确认声音和画面正常。
4. 测试“临时全屏 / 返回窗口”，再观察广播停止和再次开始。
5. 点击“停止并恢复”，检查界面是否确认清理完成；待下次正常广播确认原厂行为恢复。

第一版对新的快捷键、特定网络和 USB 限制请求也建立了精确处理点，但不重置已经存在的驱动状态。黑屏和其余远程控制当前仍显示待适配。因此这一轮重点核验持续广播和事件链，不把界面“已接入”视为所有限制已经解除。

若原 OsEasy-ToolBox 已经替换过 `ScreenRender.exe`，先通过原工具箱恢复原厂广播文件再测试本程序。不要让两个自动模式同时修改同一组件；本程序不会自动覆盖其他工具替换的文件。

## 遇到问题时保留的材料

- 程序界面最近事件的具体内容。
- `%LOCALAPPDATA%/OsEasyAuto/events.jsonl` 中对应时段记录。
- 触发的是广播、快捷键、网络、USB，还是其他类型操作。
- 停止并恢复是否成功。

记录仅用于定位这份样本的具体问题。没有在开发电脑执行原厂样本、安装脚本或真实驱动调用。
