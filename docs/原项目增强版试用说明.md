# 原项目增强版试用说明

当前入口：`dist/OsEasyToolBoxEnhanced.exe`。原工具箱的七个页面和手动功能入口保持原布局。

## 自动填教师机 IP

打开 **广播命令** 页，保持 **自动填写教师机IP** 开启。获得当前学生端控制连接或明确的广播教师地址后，地址自动进入原来的 **输入教师机IP地址** 框。然后按原来的 **由教师机IP生成远程命令** 按钮即可。

手动编辑 IP 会暂停自动覆盖。需要重新自动获取时，点击 **重新自动识别**，或重新打开自动填写开关。

等待状态表示暂时没有可靠的当前信号。`remote` 是组播时不会被当成教师机 IP；仅有单播广播来源时显示候选，多个地址冲突时也不会自动填入。

这个识别过程在打开工具箱后就运行，不要求先启用自动处理或执行原版解锁步骤。

## 自动处理

在 **进程管理** 页点击 **一键开启自动模式**，后台持续处理已经支持的新请求和广播窗口。点击停止会撤销本次监听和窗口调整。

此版本对黑屏、未知的已有驱动锁定和其余远程控制路径仍未完整覆盖；原来的手动入口继续保留。不要把“监听已接入”当成所有限制均已解除。

## 第一次核验

1. 核对输入框中自动填写的 IP 及下方来源是否符合当前教师机。
2. 确认原来的生成按钮使用自动填写的地址。
3. 手动改一次 IP，确认它没有被后台覆盖；再恢复自动识别。
4. 如使用自动模式，测试广播开始、停止、再次开始，以及退出恢复。

当前构建使用公开源码和 Flet 0.18.0。原版旁置辅助 EXE 的手动功能仍需原工具箱对应辅助文件。课堂效果尚需实机确认。
