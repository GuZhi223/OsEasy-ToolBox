# 样本适配范围

自动逻辑目前只适配一份本地教室样本，运行时以 `oseasy_auto/assets/target.json` 中的 SHA-256 校验进程和组件身份。仓库不提供样本下载，也不包含该软件的二进制和配置。

样本的学生端为 x86 `MmcStudent.exe`；广播组件为 `ScreenRender.exe`。`10.9.1.5433` 来自多个组件内一致的 PDB 构建路径，并非已从产品版本界面确认的 FileVersion。运行时以指纹为依据，不能只凭版本文字认定兼容。

原工具箱已有用户实机可正常运行的反馈，但新增自动模式和教师 IP 识别只完成开发机验证。旧工具箱的实测结果不等于本增强版已在所有教室环境中验证。

## 教师 IP

读取校验通过的学生端进程已经建立的控制连接，结合本地 `skin/core.conf` 的 `ConnectPort`；缺少文件时使用样本默认端口。还会读取可靠的广播 `teacher_ip` 参数。仅有单播 `remote` 时列为候选，组播和本机地址排除，可靠来源冲突时不自动选择。

## 自动模式边界

- 广播：处理已经定位的广播启动参数和对应窗口，保存并恢复本次修改的窗口状态。
- 特定快捷键限制：只处理已定位的设备、控制码、数据包长度和类型组合，不泛化为全部键鼠限制。
- 网络和 USB：只在指纹校验通过的已加载模块内处理明确的新限制调用，不主动重置未知的既有驱动或注册表状态。
- 黑屏及其余控制路径：尚未完整覆盖，不把“已建立观察点”显示为“全部控制已解除”。

完整测试使用自建进程和模拟 DLL，覆盖停止后的清理、窗口恢复、进程身份变化和地址误判等场景，不调用真实教室驱动。详细静态分析记录和原始文件清单仅在开发者本地保存。
